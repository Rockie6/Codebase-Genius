# 🧠 Codebase Genius

Drop in a repo URL and get back a friendly, readable set of documentation — generated by actually digging through the code, not just copying the README.

## ✨ What it does

- 🤖 Runs an end-to-end pipeline: clone → analyze → document
- 🔍 Iteratively chases down imports so it doesn't miss internal modules
- 📊 Builds a Code Context Graph (CCG) of classes, functions, and how they relate
- 🎨 Clean web UI with preview, copy, and download
- ✅ Validates URLs for GitHub, GitLab, and Bitbucket
- 🧪 Tested (26 tests, all passing)

## 🚀 Quick start

```bash
# Clone and set up
git clone https://github.com/yourusername/codebase-genius
cd codebase-genius
python3 -m venv .venv
source .venv/bin/activate
pip install -r codebase_genius/requirements.txt

# Optional: add a Gemini key for nicer README summaries
cp .env.example .env
# Edit .env and drop in your GEMINI_API_KEY

# Start the server
python start_server.py

# Open the web UI
# http://localhost:8000/gui
```

## 📖 Usage

### Web UI
1. Open http://localhost:8000/gui
2. Paste a repository URL
3. Hit "Generate Documentation"
4. Preview or download what it produces

### API
```bash
curl -X POST http://localhost:8000/generate \
  -H 'Content-Type: application/json' \
  -d '{"repo_url": "https://github.com/pallets/flask"}'
```

### Command line
```bash
python cli.py https://github.com/owner/repo
```

## 🏗️ How it's put together

The pipeline is orchestrated in `orchestrator.py`, which leans on four helpers:

- `repo_tools.py` — URL checks, cloning, file discovery
- `analyzer.py` — builds the CCG, computes stats, discovers dependencies
- `docgen.py` — turns the analysis into Markdown
- `llm.py` — optional Gemini summaries

On top of that: `api_server.py` exposes a FastAPI REST layer, and `gui/index.html` is the web interface.
